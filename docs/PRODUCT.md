# 产品定位｜视频剪辑与自动批量混剪

## 一句话介绍

VoiceMix Studio 是文案驱动的视频剪辑插件与自动批量混剪工具：文案生成语音，语音确定视频时长，从选定的大批量素材库中自动随机编排镜头，生成可修改样板，预览确认后批量导出。

当前以独立桌面应用交付，作为剪辑工作流的批量制作环节使用；尚未提供剪映、Premiere 等宿主内插件接口。

## 对外标题与简介

- 展示标题：**VoiceMix Studio｜视频剪辑插件 · 文案驱动 · 自动批量混剪**。
- 短标语：**一批文案，一库素材，自动混剪，多版输出。**
- 简介：**文案驱动的视频剪辑与自动批量混剪工具：文案转语音和字幕，选择大批量视频/图片素材库，自动随机编排多个版本，预览微调后批量导出。适合门店商户、电商投广和代运营团队复用自有素材制作广告视频。**
- English: **Script-driven video editor for automatic batch remixing: text-to-speech, reusable video/image libraries, randomized cuts, editable previews and batch exports.**

## 核心价值

把重复的时间轴搭建、配音合成与字幕铺设交给工具，把商品卖点、真实素材和内容审核留给创作者。

尤其适合“已经有素材，但需要持续生产多个广告表达版本”的业务。一次拍摄的价值不止一条成片，而是形成可复用和继续补充的素材库。

## 推荐介绍文案

> 素材拍了很多，每换一条推广文案却还要重新剪视频？VoiceMix Studio 从文案开始，自动生成语音与字幕，再从你圈定的素材库里随机编排镜头。一条文案可以生成多个剪辑版本，多条文案可以批量制作。你决定素材是否复用，工具负责重复的混剪工作；样板出来后继续选片、调节奏、改字幕，满意再统一导出。适合门店商户、电商投广和代运营团队持续制作广告视频。

## 可以延伸的使用场景

| 场景 | 文案如何变化 | 素材如何复用 |
| --- | --- | --- |
| 门店日常内容 | 到店理由、新品介绍、营业信息、环境体验 | 门头、环境、服务过程、商品特写 |
| 电商广告创意 | 商品卖点、操作步骤、使用场景、常见疑问 | 商品展示、功能演示、细节、使用画面 |
| 同一商品多角度表达 | 对同一事实写不同开头和叙述顺序 | 在同一商品目录中生成多个剪辑版本 |
| 代运营多客户制作 | 每个客户独立准备和审核文案 | 每个客户独立素材库，避免混用 |
| 周期性活动内容 | 更新日期、规则和活动信息 | 使用仍然有效且授权允许复用的素材 |

核心是缩短“已有素材 → 多个可审核视频版本”的制作流程。广告投放、效果归因和智能语义选材不能由“自动随机混剪”推导为现有能力。

## 建议的工作流

1. 素材库：按客户、门店、商品和卖点整理。
2. 文案库：每条聚焦一个卖点，确认真实性。
3. 创意批次：文案数量 × 每条生成数，先做小批次检查。
4. 精修与审核：检查画面、配音、字幕、价格与活动信息。
5. 发布与复盘：在外部平台发布，人工记录表现，反向补充素材和文案。

## 后续方向（尚未提供）

- 内置文案助手：基于商品事实生成多种表达，允许人工确认。
- 素材标签与分组规则：让常规广告混剪更准确地对应商品和文案。
- 创意批次报告：记录文案、素材与配置，方便筛选和复盘。
- 模板与品牌套件：复用门店字体、标识、配色与片尾。
- 增量更新与安装器：目前以版本目录安装和快捷方式同步为主。

以上是路线建议，不是当前版本功能承诺。
