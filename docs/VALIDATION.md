# 验证范围与限制

## 已有检查

- 覆盖静态资源、项目持久化、跨来源写入限制、图片时长、复用、批量编号与输出映射。
- MV 覆盖 LRC、歌词辅助对齐、镜头锁定、局部重做、时间轴验证与样式生成。
- 启动覆盖单实例、窗口先于后端、页面就绪与超时恢复、桥接私有窗口引用。
- 本机完成过两条真实文案独立配音与实际混剪，以及三种歌词样式、三种画幅和 4K 片段出片。
- 原生白屏复现日志显示桥接遍历公开窗口对象导致递归。改为私有 _window 后，打包窗口约 2 秒收到初始化确认。

精确测试数量和本次结果以 CI 与 Release 说明为准。历史检查不等于任意素材或设备无故障。

## 边界

- 在线配音需要网络和上游服务可用，不提供服务等级承诺。
- 歌曲混响与特殊唱法可能导致识别或对齐偏差；普通 LRC 逐字时间为估算。
- MV 场景分析为有限分类，不能保证理解所有歌词。
- 素材不足时版本可能相似，数量不等于视觉差异或广告效果。
- URL 下载受站点、登录和网络限制，不保证所有链接可用。
- Mac 通过构建后仍需窗口、文件选择、配音与导出实机验收。
- 高码率、4K 和批量渲染增加时间与磁盘开销，原素材质量仍是上限。
- 不自动审核行业资质、广告真实性、素材授权或投放规则。
