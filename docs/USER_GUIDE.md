# 使用指南

## 准备可复用素材库

按业务或客户分文件夹。饮品店可以放入门头、环境、制作、包装与商品特写；电商可以放入商品外观、细节、操作和使用场景。

素材越丰富，镜头组合越有空间。软件不会凭空生成产品拍摄画面，也不会自动理解所有文案含义。文案混剪按时间轴和节奏组织所选素材；MV 的有限场景分类仍需人工检查。

## 准备文案

每条文案聚焦一个主要卖点。当前版本不内置 AI 文案生成，可手写或借助外部工具，再粘贴到 APP。

**单文案模式：** 一条完整文案可包含多行，设置生成数量后产生多个剪辑版本。

**多文案模式：** 按编号、空行、每行或独立分隔线识别，列表显示预计生成数量。编号步骤可能被误当成新文案，因此包含复杂段落时推荐使用 `---`。

```text
文案1：下班后，给自己留一点轻松的时间。
---
文案2：今天来看看，这份新品是怎样制作出来的。
```

示例：[store-scripts.txt](../examples/store-scripts.txt)。一次最多 200 个视频，10 条文案 × 每条 3 个 = 30 个。

## 选择视频工作区域

在素材路径处选择文件夹或单个文件，扫描确认可用素材。“工作区域”指允许软件选用的素材范围，不是屏幕录制区域。

- 常规广告制作：勾选允许重复使用素材，让同一批自有素材服务多条文案。
- 强调新素材：取消勾选。使用记录会影响后续任务；素材不足时补充素材，或明确允许复用。
- 不同客户：使用不同素材文件夹，避免混入其他客户的镜头。

## 设置声音与画面

选择音色和语速。文案配音的实际长度决定时间轴需要覆盖多久，可选择配乐或关闭配乐。

右侧可设置字幕、封面、滤镜和转场。滤镜先作用于画面，再叠加文字。图片默认居中铺满；横图转竖屏会裁切，请检查主体是否保留。

## 先粗剪，再正式导出

粗剪用于快速检查内容、镜头与字幕。结果可继续调整镜头顺序、素材入点、时长、替换素材和字幕，并从正式成片选择封面。

正式导出重新使用原素材渲染，不是把低清预览简单放大。低清原素材仍会限制成片细节。

批量生成后逐条检查商品/门店是否对应、字幕是否准确、镜头是否重复过多、声音是否舒适。

## MV 模式

导入歌曲，选择以下入口：

1. 纯文字歌词：每行一句，使用本地识别结果辅助对齐。
2. 只有音频：自动识别歌词和时间，须人工检查。
3. LRC：导入已有时间标签；普通 LRC 的逐字时间为估算，增强 LRC 可保留词级标签。

选择整首或推荐片段，勾选素材，选择电影叙事、情绪写真、节奏混剪或舞台演唱。舞台演唱需要已有演唱素材，不生成口型表演。

歌词可选逐句、逐字变色或上下滚动。时间轴可校正歌词时间，锁定满意镜头并只重做其他部分。

正式 MV 默认竖屏 1080p / 40 Mbps，可选横屏、方形、4K 和其他码率。40 Mbps 一分钟约 300 MB，实际大小受时长、容器和音频开销影响。

## 保存与更新

保存项目后，升级继续使用同一应用数据目录。项目引用原素材路径，跨电脑迁移还需同步原素材与成片。

`scripts/install_windows.py` 安装到用户程序目录的版本子目录，并更新 VoiceMix 快捷方式。不要继续使用历史 `build/...` 临时入口。

更新前保存编辑内容，等待任务完成；退出兼容服务或关闭原生窗口，再启动新版本。页脚版本号应与下载包版本一致。

## 常见问题

**仍显示旧版本？** 先看页脚版本号，关闭旧服务后从新安装入口启动。兼容服务不会随浏览器标签页关闭而自动退出，请点页面底部退出按钮。

**白屏？** 新版已修复桥接递归并监测页面就绪。仍无法打开时用 `--browser`；显卡显示异常可尝试 `--software-rendering`。反馈时附版本和去除隐私的 startup.log 错误片段。

**找不到 FFmpeg？** 安装 ffmpeg 和 ffprobe，加入 PATH，或在桌面版选择工具目录后重启。

**配音失败？** 检查联网情况，减少并发重试。在线语音服务的可用性不由本软件保证。

**很多视频相似？** 同一文案、极少素材会限制变化。增加拍摄角度、场景、时段和文案卖点，再分组检查结果。

**会保证过审或起量吗？** 不会。工具负责制作，内容真实性、素材权利、行业要求和投放策略仍需使用者检查。
